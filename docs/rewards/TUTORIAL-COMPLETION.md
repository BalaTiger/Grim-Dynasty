# 教程状态规则与十级升级闭环

本阶段恢复GameEngine::UnlockTutorialPage（0x1802D97D0）、ShowTutorialPage（0x1802D98F0）的值与事件规则，并接入升级帮助函数0x18028E990的主角十级分支。统一构建通过721条断言（本次26条）、10个独立场景，仍为10个原创DLL模块。[验收数据](acceptance-tutorial.json)保存本次构建清单与源码/证据指纹。

## 输入、输出与顺序

输入为uint页号、bool通知开关、明确的64位页面数量、32位字数组位图、有序解锁列表和事件路由上下文。越界页号直接返回，已解锁页跳过列表与事件依赖。首次解锁先设置page>>5字内的page&31位，再追加页号；notify=true才产生Kind=0x36、页号位于+4的事件，分发到路由0x36。notify=false不依赖事件管理器。GetTutorialUnlockList（0x1802D97C0）证实列表在引擎+0x36CA0；位图在+0x36CB8，位数在+0x36CD0。遵循正常有效内存和成功分配的值语义，没有模拟原分配器或无效指针行为。

ShowTutorialPage只检查页号范围；它既不检查也不写解锁位图，重复显示仍分发。特别是事件内容Kind仍为0x36，而实际路由是0x37。两者在原创模型中分别保存，未按名字猜成同一编号。

ScriptableAction_UnlockTutorial::Execute（0x18046E810）读取自身+0x10字段，以true尾跳到解锁函数。反汇编明确为JMP，补足反编译器terminal-call限制。共享Read入口0x18046ACA0读一个32位字段；本阶段提供ExecuteAction页号入口，未声称自动接通全部QST动作执行器。

## 升级与任务场景

主角每次跨到十级时，教程页0x14在该级属性/技能点流程之前解锁。预检深复制教程位图、列表、产出队列；所有未覆盖依赖都在实际写入前拒绝。多级跨越保留此前技能通知、十级教程通知、十级技能通知、最终等级通知的顺序；已解锁十级页不重复产生通知。非主角分支不依赖教程。

原创“边军研阵”接受任务后收到两次击杀事件，自动完成并奖励75经验。原创公式playerLevel*100驱动9→10级：最终XP925、技能点3、属性点1，位图word0为1048576，列表追加20，事件顺序54→49→48，字幕逻辑队列及奖励UID1正常写入。没有调用原程序或渲染器。

边界测试覆盖0/31/32/63/64/74页、等于上界与uint最大页号、重复解锁、通知关闭、缺失位字、未知计数、非空订阅者拒绝、显示路由分离、多级事件交错，以及后续奖励失败时任务/XP/位图/列表/通知全不提交。现有695条断言和9个场景回归通过。
