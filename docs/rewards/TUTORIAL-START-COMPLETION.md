状态已为2或运行阻断非零时不执行首次接受教程。阻断路径依原规则写2并跳过目标回调。无标志4时无需教程上下文。已解锁或页55越界时解锁是已证明的无操作，仍继续任务启动。未知onAccept动作、教程事件非空订阅者、后续目标校验失败均在任何教程/任务/注册写入前拒绝。
