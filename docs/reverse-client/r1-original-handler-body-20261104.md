## 与点击移动主链的连接

| 原 EXE RVA | 已核内容 | 证据边界 |
|---|---|---|
| `21040/21049`、`21060/21069` | 经 GraphicsEngine 取得高度、宽度，再转单精度浮点 | 名称来自固定 EXE 的静态导入库存；这些槽本轮未读运行时值 |
| `21080`、`21098` | `IsMouseLocked` 非零、或 `IsRenderingEnabled` 为零时转 `226B6` | Game 描述符 #9 的 20 字节新读与同哈希有序导入库存相互校验；不是运行时调用证明 |
| `210A6..210D5` | 读取事件 `+4/+8` 的浮点值，进行 `0≤x<width`、`0≤y<height` 的范围筛选 | 需浮点比较正常返回；NaN、异常/MXCSR 语义不以默认值补齐 |
| `2176C..217E0` | 从事件坐标减去 Widget `+60/+64` 的整数起点，再除以 `+68/+6C`，向 `WorldCamera::GetImagePoint` 传入 Vec2 与 `this+60` viewport | 字段名称是依据算术和调用参数的解释；viewport 的实际构造、零尺寸及原 UI 布局尚未闭合 |
| `22607` | `CALL [IAT 2D78A0]` 静态绑定 `ControllerPlayer::HandleActionFromMouse` | 具体 bool、WorldVec3、引用参数的生产路径仍有条件和未展开依赖；该运行时槽本轮未采样 |
| `226B6..226DC` | 清 AL 后恢复寄存器并返回 | 只证明 AL=0，不是全部 RAX 清零 |

`217E0` 是 **WorldCamera** 的 WorldVec3 返回接口，不能直接等同早期 **Camera** 的 Vec3 接口。事件浮点坐标也不能直接拿此前采到的整数坐标尾事件代替。按调用点接通现有模型前，仍需核对这两个层级。

`22607` 的参数包含共享 WorldVec3、可写 ObjectId 引用以及 `widget+1D0` 的 bool 指针，不能复制后再同步这些状态。该调用返回 AL 被保存用于后续字段分支，而正常续行的 `22677` 会把 Widget 消费返回置 1；因此 **Widget 返回 1 不代表动作返回 true，更不代表角色移动成功**。
