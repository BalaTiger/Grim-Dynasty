# 自动目标更新与事件调度（静态还原子域）

当前可运行链已由显式Complete(false)推进为：Start→Update记为未满足→已解码token入站→Update自动执行空完成事件域的Complete(true)值语义→完成查询→Reset。运行 `.tooling/task-auto-build/AutoQuestDemo.exe`，或用 `src/task_auto/build_auto.ps1`重编译。原创夹具不读原版DLL、资源、Steam、存档或网络。

## 恢复语义

Engine.dll实际Rea证据在rea-engine/，Game.dll Task.Update/Complete/AdjustRewards证据沿用docs/task-runtime/rea/，不是按演示反推实现。

- EventManager.Register 0x180080fa0：按uint32事件键获取/创建列表，按处理器对象身份去重，尾部追加。
- UnRegister 0x180081110：同样先获取/创建列表；注销缺失键会产生空行。移除首个身份匹配项并保持其他顺序，不移除空行。
- Send 0x180081230：缺失键不创建行；在可重入临界区内按当前列表下标调用，每次回调后重读长度。回调追加会在同轮遇到，自注销导致移位后的下一项被下标递增跳过。C#锁保留同线程重入契约，未声称复刻Windows锁的调度时序。
- 路由键来自Send第二参数，不从payload.Kind推导。调试日志分支尚未恢复：存在事件行且debug不明确为false时返回Unsupported；缺失行不会进入日志分支。
- 通用调度器可以调用显式提供的自有处理器。它们是调用者契约，**不是恢复了原版处理函数**。遇到未知处理器返回Unsupported，并披露此前已投递数量/PartialEffects，不声称回滚已发生的回调。4096次投递预算是工具支持域上限，不是原生限制；无限追加/无限递归不在支持域。
- Task.Update目标状态0/1/2：初始0根据条件写1（满足）或2（未满足）；2→1时会执行目标动作，因此仅空动作域支持；1→2标记退化。Wait不跳过。目标初始化触发通知但两通知字节为0，后续满足/退化将两字节设1。空目标或无变化不自动完成。
- 目标变化后发送事件0x2a，再在所有目标非2时完成任务。自动链当前要求事件0x2a订阅列表已知为空，条件changed字节明确为0；非空订阅、未知字节和OnChanged路径Unsupported。
- 自动Complete(true)当前只覆盖完成事件空、目标动作空、已知主玩家/进度字节、已知出站提供者、无需网络发送的域。除状态/完成银行外，还把+A3至当前难度的奖励历史字节置1。没有奖励发放。实现复用前批无奖励完成纯值写入，再补历史字节；在已证实无观察者/无动作/空生命周期钩子的输入域内最终可观察状态相同，不宣称内部指令时序相同。

条件支持域为已恢复且不依赖任务状态变化的IsLevel/IsDifficulty/IsHardcore/HasToken/Wait/ServerHasToken/AnyoneHasToken v0。任务引用条件与有未知生命周期的类型仍Unsupported。整个自动更新先检查全部依赖再提交快照写入；Unsupported时任务/目标/奖励记录不变。通用调度器的PartialEffects边界与该预检原则分别说明，不混淆。
